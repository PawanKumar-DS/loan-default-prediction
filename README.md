# \# 🏦 Loan Default Prediction

# 

# A Machine Learning project that predicts the likelihood of a customer defaulting on a loan using a Random Forest Classifier.

# 

# \## 📌 Project Overview

# 

# Loan default prediction is a classification problem where the goal is to identify customers who may fail to repay their loans.

# 

# This project includes:

# 

# \- Data preprocessing

# \- Exploratory Data Analysis (EDA)

# \- Feature encoding

# \- Multiple Machine Learning models

# \- Model evaluation

# \- Random Forest model selection

# \- Streamlit web application

# \- Loan default probability prediction

# \- Risk level classification

# \- Downloadable prediction report

# 

# \## 🚀 Features

# 

# \- 👤 Customer information input

# \- 🎯 Loan default prediction

# \- 📊 Default probability

# \- 🟢 Low Risk classification

# \- 🟡 Medium Risk classification

# \- 🔴 High Risk classification

# \- 📥 Downloadable prediction report

# \- 📈 Model performance metrics

# \- 🌐 Streamlit web application

# 

# \## 🛠️ Technologies Used

#

# \- NumPy

# \- Matplotlib

# \- Seaborn

# \- XGBoost

# \- Joblib

# \- Jupyter Notebook

# \## 🤖 Machine Learning Models

# 

# The following models were evaluated:

# 

# 1\. Logistic Regression

# 2\. Decision Tree Classifier

# 3\. Random Forest Classifier

# 4\. XGBoost Classifier

# 

# \### Final Model

# 

# \*\*Random Forest Classifier\*\*

# 

# The Random Forest model was selected based on the F1 Score among the evaluated models.

# 

# \## 📊 Model Performance

# 

# | Metric | Score |

# |---|---:|

# | Accuracy | 77.54% |

# | Precision | 26.99% |

# | Recall | 54.76% |

# | F1 Score | 36.16% |
